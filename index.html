PocketPigeon · Quick start

Run it in three steps

PocketPigeon is two halves: a browser extension and a small relay that runs on your computer.

  1. Start the relay

    On Windows, unzip and double-click start-relay.cmd. Otherwise run cd server && npm install && npm start. Keep the window open.

  2. Load the extension

    Open chrome://extensions, enable Developer mode, choose Load unpacked and select the extension folder.

  3. Pair your phone

    Put the phone on the same Wi-Fi, open the extension and scan its QR code. Messages are encrypted on both devices.

Node.js 20+ · Windows, macOS or Linux · The relay only stores ciphertext.
