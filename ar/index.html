شغّله في ثلاث خطوات

PocketPigeon نصفان: إضافة للمتصفح، ومرحّل صغير يعمل على حاسبك.

  1. شغّل المرحّل

    على ويندوز، فك ضغط الملف وانقر نقرًا مزدوجًا على start-relay.cmd. أو نفّذ cd server && npm install && npm start. أبقِ النافذة مفتوحة.

  2. حمّل الإضافة

    افتح chrome://extensions، فعّل «وضع المطوّر»، اختر تحميل غير مضغوط وحدد مجلد extension.

  3. اقرن هاتفك

    ضع الهاتف على نفس شبكة Wi-Fi، افتح الإضافة وامسح رمز QR. تُشفّر الرسائل على الجهازين.

Node.js 20+ · ويندوز أو macOS أو Linux · لا يخزّن المرحّل سوى النص المشفّر.
